## Feature contract matrix

| Surface | Primary lexicons | Status | Regression coverage |
| --- | --- | --- | --- |
| Posts and embeds | `app.bsky.feed.*`, `app.bsky.embed.*` | Supported; unknown open-union embeds render as unsupported content | Post and unknown-embed JSON fixtures |

| Notifications | `app.bsky.notification.*` | Supported by the generated 0.25.8 API | Existing notification reducer and rendering tests |
| Profiles and graph | `app.bsky.actor.*`, `app.bsky.graph.*` | Supported by the generated 0.25.8 API | Existing profile navigation and service compilation |
| Direct messages | `chat.bsky.convo.*` | Supported for the currently exposed conversation operations | Existing feature-service compilation |
| Moderation | `app.bsky.labeler.*`, moderation and report lexicons | Supported for the currently exposed moderation operations | Existing moderation decision tests |

Open unions must never be destructured with an assumption that every future `$type` is known.
Display paths should retain context and show an `Unsupported` placeholder for `Union::Unknown`.
When updating either SDK crate, run:

```sh
cargo test --all-targets
cargo clippy --all-targets -- -D warnings
```

Then add or update a JSON fixture for every changed response contract before changing this baseline.
